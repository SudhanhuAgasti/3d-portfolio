# 3D Interactive Portfolio — Sudhanshu Kumar Agasti

A high-performance, 3D scrollytelling personal portfolio crafted with a 300-frame canvas animation sequence, Locomotive smooth momentum scroll, and GSAP ScrollTrigger.

## 🚀 Tech Stack
- **Frontend:** Vanilla HTML5, CSS3 (Modern custom property tokens, glassmorphism, clamp-based fluid responsiveness), Modern ES6+ JavaScript
- **3D Animation & Rendering:** HTML5 Canvas 2D frame sequencer with DPR (Retina) scaling
- **Motion & Interaction:** Locomotive Scroll v3.5, GSAP v3.11, ScrollTrigger
- **Icons:** Lucide Icons & Crisp Inline SVGs

## 📁 Key Features
- **3D Character Background:** Continuous frame-by-frame character interaction synchronized with entire page scroll depth.
- **Glassmorphic Floating Panels:** High-contrast, frosted glass panels highlighting Professional Summary, Work Experience (Rooman Technology), Technical Skills, Featured Projects, and Education.
- **Progressive Asset Preloader:** Real-time percentage indicator tracking all 300 sequential PNG frames before entrance.
- **Micro-Interactions:** Hardware-accelerated custom trailing cursor and fluid mobile drawer navigation.

## 🛠️ Local Development
Simply open `index.html` in any modern web browser or serve via:
```bash
npx serve .
# or
python -m http.server 3000
```
